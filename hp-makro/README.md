# HP Makro

Aplikacja na Androida (11+): na ekranie podglądu gry pilnuje paska HP.
- HP poniżej max (poza walką): globus -> Przerwij -> oko.
- HP pełne: globus -> Walcz.

Działa jako usługa dostępności (zrzuty ekranu + kliknięcia). Po włączeniu usługi u góry ekranu
pojawia się pasek stanu; dotknięcie go uruchamia/zatrzymuje makro.

APK budowany jest automatycznie przez GitHub Actions i publikowany w wydaniu `hp-makro`:
https://github.com/Racimir/Factorio-mod/releases/latest/download/HP-Makro.apk
